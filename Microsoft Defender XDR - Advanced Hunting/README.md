# Microsoft Defender XDR — Advanced Hunting

Biblioteca pública de consultas KQL para postura de dispositivos, configurações, vulnerabilidades e cobertura do Defender for Endpoint.

## Regras

- Não publicar resultados reais, nomes de dispositivos, usuários, IPs ou IDs.
- Executar as consultas no Microsoft Defender portal.
- Validar licenciamento e disponibilidade das tabelas.
- Tratar recomendações como direcionadores; não automatizar remediações sem testes.
- Não classificar como testada sem evidência de execução.

## Catálogo

| Nº | Consulta |
|---:|---|
| 01 | Configuracoes de Seguranca Nao Conformes |
| 02 | Resumo de Recomendacoes de Configuracao |
| 03 | Vulnerabilidades e CVEs por Dispositivo |
| 04 | Cobertura e Saude do Defender for Endpoint |

## Status

Todas as consultas estão classificadas como **REVISADAS ESTRUTURALMENTE** e não foram executadas em tenant.
